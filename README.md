# snepking.com

MR.UNKNOWN's art gallery and links. Static site served by Cloudflare Pages.

- `index.html` holds the page and its data (pieces, genres, links).
- `art/` holds the images: full-size files plus `_t` thumbnails for the grid.

No build step: Cloudflare Pages serves this folder as-is (build command empty, output directory `/`).
